# 시설팀 당직일지

휴대폰으로 검침값·순찰 결과를 입력하면 전일검침·사용량·증감·월누계가 자동 계산되고, 일지를 미리보고 엑셀(원본 양식)로 저장하는 웹앱입니다.
화면은 GitHub Pages(무료), 데이터는 Supabase(무료)에 저장됩니다. 로그인 없이 **팀 코드**만 기기마다 한 번 입력합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 주소. 열면 업무일지로 이동합니다 |
| `duty.html` | 당직일지 |
| `schedule.html` | 근무표 (3교대 달력, 근무 교대 드래그, 통계, PDF·근태 엑셀) |
| `journal.html` | 업무일지 (날짜별 메모, 전체 검색, txt 가져오기·내보내기) |
| `docs.html` | 문서 보관·검색 (업로드, 분류, 열기·내려받기) |
| `mof.html` | MOF 계량기 계산 (수전일지 한전 계량기 4~8번 → 검침차·×720·금일 사용량) |
| `config.js` | Supabase 주소·키, 날씨 위치 (**직접 수정**) |
| `supabase.sql` | 데이터베이스 설정 (Supabase에서 1회 실행) |
| `supabase_journal.sql` | 업무일지 테이블 (`supabase.sql` 다음에 1회 실행) |
| `supabase_docs.sql` | 문서 보관용 테이블 (`supabase.sql` 다음에 1회 실행) |
| `template.xlsx` | 엑셀 저장용 원본 양식 |
| `worklog.js` | 업무일지 엑셀 출력(기존 변환 프로그램의 양식 파일·결재칸 그림 내장) |
| `vendor/` | 엑셀·PDF·ZIP 라이브러리 (외부 CDN 없이 동작) |

## 설치 (약 15분, 1회)

### 1. Supabase
1. https://supabase.com 가입 → **New project** (Region: Northeast Asia (Seoul) 권장, DB 비밀번호는 따로 보관)
2. 왼쪽 **SQL Editor** → `supabase.sql` 내용을 통째로 붙여넣기
3. 맨 아래 줄 `'change-me-1234'` 를 팀 코드로 바꾸기 — **영문·숫자 4자 이상**, 추측 어려운 값
4. **Run** → "Success" 확인
   - 문서 기능을 쓰려면 이어서 `supabase_docs.sql` 내용도 새 쿼리로 붙여넣고 Run
5. **Project Settings → API**(또는 API Keys)에서 두 값 복사
   - Project URL (`https://xxxx.supabase.co`)
   - publishable 키(`sb_publishable_...`) 또는 legacy **anon** 키
   - ⚠️ `secret` / `service_role` 키는 절대 쓰지 마세요

### 2. config.js 수정
```js
supabaseUrl: 'https://xxxx.supabase.co',
supabaseKey: 'sb_publishable_xxxx',
lat: 37.5665, lon: 126.978,   // 병원 위치 (날씨 자동 입력용)
```

### 3. GitHub Pages
1. GitHub에서 **New repository** → 이름 예: `facility-duty` → **Public** (무료 계정은 Public 저장소만 Pages 가능)
2. **Add file → Upload files** → 이 폴더의 파일 전부(`vendor` 폴더 포함) 끌어다 놓기 → Commit
3. **Settings → Pages** → Source: *Deploy from a branch*, Branch: `main` / `/ (root)` → Save
4. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/facility-duty/`) 접속 — 업무일지(오늘 날짜 메모)가 첫 화면으로 열립니다

### 4. 팀원 배포
- 주소와 팀 코드를 팀원에게 따로 전달 (같은 메시지에 같이 보내지 않기)
- 휴대폰: Safari/Chrome에서 열고 **홈 화면에 추가**
- 카카오톡 안 브라우저에서는 파일 저장이 막힐 수 있으니 외부 브라우저로 여세요

## 첫 사용
**기록 탭 → 시작 기준값**에 앱을 쓰기 시작하는 날의 **전날 종이 일지 값**(전일 검침·전일 사용량·월누계, 전월 말일 검침)을 한 번 입력합니다. 이후엔 앱 기록이 자동으로 이어집니다.

## 보안 — 무엇이 막히고 무엇이 안 막히나
- 저장소가 Public이라 코드와 Supabase 키는 누구나 볼 수 있습니다. 이 키만으로는 **읽기·쓰기 불가** — 팀 코드가 있어야 합니다(서버에서 검사).
- **삭제는 불가능**합니다(앱·API 모두). 덮어쓰기 전 값은 `private.history`에 자동 보관됩니다.
- 팀 코드를 아는 사람은 내용을 고칠 수 있습니다. 퇴사자 등이 있으면 코드를 바꾸세요:
  ```sql
  delete from private.team; insert into private.team values ('새코드');
  ```
  → 모든 기기에서 새 코드를 다시 입력하게 됩니다.
- 이 앱은 사용자별 로그인이 없으므로 "누가 고쳤는지"는 기록되지 않습니다.

## 데이터 보호
- 지하 등 신호가 없는 곳에서 입력하면 **기기에 보관** → 연결되면 자동 전송 (상단에 "오프라인 · 기기에 보관 중" 표시)
- 같은 날짜를 두 사람이 동시에 고치면 **나중에 저장한 쪽이 이깁니다**(이전 값은 history에 남음)
- **기록 탭 → 백업 · 설정 → 전체 백업 받기**: 월 1회 권장
- 잘못 덮어쓴 값 되살리기 (Supabase SQL Editor):
  ```sql
  select replaced_at, data from private.history where key = '2026-10-23' order by replaced_at desc;
  ```

## 무료 요금제 주의
- Supabase 무료 프로젝트는 **7일간 사용이 거의 없으면 일시정지**됩니다. 매일 입력하면 해당 없음. 정지되면 대시보드에서 **Resume project**로 복구(데이터 유지).
- 날씨는 Open-Meteo(무료, 키 없음)의 **일 단위 예보/관측**입니다. 하루 중 가장 나쁜 날씨 코드가 표시되므로(예: 잠깐 이슬비 → "비") 필요하면 직접 고치세요. 비어 있을 때만 채우고, 고친 값은 덮어쓰지 않습니다.

## 인쇄
일지 탭은 미리보기 전용입니다. **엑셀 저장**으로 받은 파일을 엑셀·한셀에서 열어 인쇄하세요(원본 양식 그대로).

## 화면 이동
- 모든 화면 위쪽과 **아래쪽**에 같은 메뉴(업무일지 / 당직일지 / 근무표 / 문서)가 있습니다. 길게 스크롤한 뒤에도 아래 메뉴로 바로 이동합니다. 폰에서 글자를 입력하는 동안에는 키보드 공간을 위해 하단 메뉴가 숨겨졌다가 입력이 끝나면 다시 나타납니다.

## 근무표
- 상단 메뉴의 **근무표**로 이동합니다. 당직일지와 같은 팀 코드를 씁니다(한 번 입력하면 둘 다 통과).
- 근무자 이름·직급·연락처와 교대 내역은 **저장소가 아니라 Supabase(config 표)** 에 있습니다. 저장소는 Public이라 코드에 개인정보를 넣지 않습니다.
- 근무자 정보 변경: 근무표 → **근무자 설정**. 달력의 이름을 끌어 다른 날 칸에 놓으면 근무 교대입니다.
- 공휴일은 코드에 2025~2027년까지만 들어 있습니다. 2028년부터는 `schedule.html`의 `holidays` 목록에 추가해야 합니다(임시공휴일 포함).
- 근무자는 3명 고정 구조입니다(근태 엑셀 양식이 3명 기준).
- 교대 끌어놓기는 PC 마우스 기준입니다. 휴대폰에서는 달력 폭이 맞지 않아 PC에서 보는 것을 전제로 합니다.

## 문서
- 상단 메뉴의 **문서**. 같은 팀 코드를 씁니다. 제목·분류·메모·파일명으로 검색하고, 분류 버튼으로 걸러 봅니다.
- **문서 올리기**: 분류를 고르거나 새로 입력 → 파일 여러 개 선택 → 제목 확인 → 올리기. 파일 1개당 최대 25MB.
- **열람**(제목을 눌러도 됨): 엑셀(.xlsx)은 시트 탭이 있는 표로, 워드(.docx)·이미지·텍스트(.txt/.csv)는 앱 화면 안에서 열립니다. 엑셀 안의 전화번호는 누르면 바로 전화가 걸립니다. PDF는 기기 기본 뷰어로 새 탭에서 열립니다.
- **열람이 안 되는 형식**: 한글(.hwp), 구형 엑셀(.xls), 파워포인트 등은 내려받기만 됩니다. 자주 보는 문서는 PDF나 .xlsx로 올리세요.
- 한 번 열어 본 문서는 그 기기에 보관되어 다음부터 즉시 열립니다.
- 엑셀 열람은 시트당 1,000행·40열까지 표시합니다(넘으면 안내). 복잡한 서식은 단순 표로 보입니다.
- **삭제는 없고 숨김만 있습니다.** 숨긴 문서는 목록 아래 "숨긴 문서 보기"에서 복원합니다. (저장소가 잘못된 삭제를 막기 위한 설계)
- 파일은 Storage가 아니라 **DB에 조각으로 저장**됩니다. Supabase 무료 DB 용량은 **500MB**라서, 문서를 많이 올리면 이 한도가 먼저 찹니다. 대시보드 Database 사용량을 가끔 확인하세요.
- 문서는 인터넷 연결이 있어야 올리고 볼 수 있습니다(오프라인 보관 없음).
- 문서는 **팀 코드를 아는 누구나** 읽습니다. 공개돼도 되는 문서만 올리세요. 계약서 원본·개인정보가 든 파일은 올리지 마세요.

## 업무일지
- 메모장처럼 **날짜별 내용이 위에서 아래로 이어져 있고, 맨 아래가 오늘**입니다. 스크롤해서 전일·지난 기록을 그대로 훑어볼 수 있습니다. PC와 폰이 같은 내용을 봅니다.
- 글을 누르면 그 자리에서 바로 고칠 수 있고, 입력 후 약 1초 뒤 자동 저장됩니다. 다른 기기의 변경은 15초 안팎으로 반영됩니다(실시간이 아니라 주기적 갱신).
- **찾기**: 상단 검색창은 스크롤해도 따라옵니다. 일치하는 글자가 노랗게 표시되고, 가장 최근 일치부터 시작해 ▲(과거 방향)·▼(최근 방향) 또는 Enter로 이동합니다. 단어를 띄어 쓰면 각 단어를 모두 표시합니다. **목록**을 누르면 모든 단어가 들어 있는 날짜만 모아 보여 주고, 누르면 그 위치로 이동합니다.
- **날짜 이동**으로 원하는 날짜로 점프합니다. 기록이 없는 날짜를 고르면 새 칸이 생기고 바로 입력할 수 있습니다. **↓ 맨 아래** 버튼으로 오늘로 돌아옵니다.
- **가져오기·내보내기**(화면 맨 아래): `<1월 1일 목요일>` 형식의 메모장 파일을 날짜별로 가져옵니다. 이미 내용이 있는 날짜는 기본으로 건너뜁니다. 내보내기는 같은 형식의 .txt로 받아 백업할 수 있습니다.
- 같은 날짜를 두 기기에서 동시에 고치면 나중에 저장한 쪽이 이깁니다(덮어쓰기 전 내용은 `private.history`에 남음). 오프라인이면 기기에 보관했다가 연결되면 전송합니다.
- 삭제 기능은 없습니다(내용을 비우는 것은 가능). 팀 코드를 아는 사람은 누구나 읽고 고칠 수 있습니다.
- **첫 화면**: 앱 주소를 열면 업무일지가 열리고, 오늘 날짜 메모가 화면 위쪽에 오도록 위치합니다(바로 위에 전일 내용이 보임).
- **전달사항**: 메모장 맨 아래에 날짜와 무관한 고정 메모칸이 있습니다. 매일 전달하는 내용을 적어 두는 곳으로, 일지·찾기·내보내기에는 포함되지 않습니다. 입력하면 자동 저장되고 PC·폰에서 같은 내용이 보입니다. (Supabase `config` 표의 `journal:notice` 한 줄에 저장)

## 업무일지 엑셀 출력
업무일지 화면 아래 **업무일지 다운로드** → 날짜 선택 → **저장(엑셀)**. 기존 변환 프로그램(메모장→엑셀)이 쓰던 양식 파일에 같은 규칙으로 채웁니다.
- 채우는 곳: 날짜(B8), 인원현황 기본값(3/1/1/1/1), 업무내용(14행부터). 줄 앞의 `-` 한 개는 제거, `ㄴ`으로 시작하는 줄은 그대로.
- 업무내용 뒤에 야간순찰·병실 보수 고정 문구와 비고 4행이 붙습니다.
- 파일명 `시설팀-업무일지-YYYY.MM.DD.xlsx`. 소모품·열외자·인원 변동은 엑셀에서 직접 고치세요.

## MOF (수전일지 한전 계량기 계산)
메뉴 **MOF** → 날짜 선택 → 원본 엑셀의 '한 전 계 량 기' 표와 같은 모양(4~8번 행 × 금일지침·전일지침·검침 차·×720·금일 사용량·월누적 사용량)에서 4~8번 **금일지침**만 입력합니다. 수식은 수전일지 엑셀과 같습니다: 검침차 = 금일 − 전일, ×720 = 검침차 × 720, 금일 사용량 = 유효(4+5+6)·무효(7+8)의 ×720 합.
- **전일지침**은 전날 날짜에 저장된 금일지침을 자동으로 가져옵니다(회색 글씨). 전날 기록이 없으면 직접 입력하고, 직접 고친 값이 우선합니다.
- **월누적 사용량** = (금일지침 − 전월 말 검침) × 720. 전월 말 검침값이 있어야 계산되므로 표 아래 접이식 칸에 달마다 한 번만 넣습니다. 비워 두면 월누적 칸은 —.
- 입력값은 `config` 테이블(`mof:날짜`, `mof:base:연-월`)에 저장되어 폰·PC가 같이 봅니다. 따로 SQL을 실행할 필요는 없습니다. 덮어쓴 값은 기존 이력 보관 장치가 남깁니다.
- 금일지침이 전일지침보다 작으면 경고만 표시하고 계산은 그대로 합니다(입력 확인용).

## 전달사항 · 팀장 지시사항 (업무일지 맨 아래)
날짜와 상관없이 고정으로 쓰는 메모입니다. 구역(디바이더)으로 나뉘며 기본은 **전달사항**, **팀장 지시사항(주황 글씨)** 두 개입니다.
- 구역 이름은 제목 칸을 눌러 바로 고치고, 동그란 버튼으로 글자색(기본/주황/빨강/초록/파랑)을 바꾸고, **삭제** / **추가**로 늘리고 줄입니다.
- 서버에는 `config` 표의 `journal:notices` 한 줄로 저장됩니다. 구역마다 수정 시각을 갖고, 두 기기가 서로 다른 구역을 고치면 둘 다 보존됩니다(같은 구역을 동시에 고치면 나중에 고친 쪽이 남음).
- 삭제는 서버에 삭제 표시로 남고, 덮어쓰기 전 값은 `private.history`에 보관됩니다.
- 예전 단일 '전달사항'(`journal:notice`)은 첫 구역으로 자동 이어집니다.
